# HumanSearch G3 모호 접미사 계약 — 파일 확장자이면서 동시에 실제 등재된 TLD 인 것들.
#
# 2026-08-25 V1 1·2라운드가 양쪽에서 때린 지점이다:
#   F5 (1라운드) 이것들을 "파일 확장자"로 면제했더니 `"vendor.zip"` 같은 실호스트가 통과했다.
#   K7 (2라운드) 그래서 면제를 빼자 `"conftest.py"`·`"README.md"` 같은 정상 파일명이 위반이 됐다.
# 둘 다 맞는 지적이다. 접미사만 보면 파일명과 호스트를 구분할 수 없다.
#
# 그래서 접미사가 여기 있으면 **같은 줄의 문맥**으로 가른다:
#   줄에 주소 문맥(scheme `://`, `@`, host/domain/url/origin/endpoint/server/portal/site 같은
#   낱말)이 있으면 호스트로 보고 거부, 없으면 파일명으로 보고 통과.
#   F = "conftest.py"          → 통과 (파일명)
#   HOST = "hire-portal.py"    → 거부 (주소 문맥)
# scheme 이 붙은 형태(`https://vendor.zip`)는 문맥 판정 이전에 평면 scheme 규칙이 잡는다.
#
# ⚠ 여기에 모호하지 않은 실 TLD(com·kr·io·net …)를 넣지 마라. 그건 게이트를 무력화한다.
