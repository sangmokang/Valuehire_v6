# 야간 자율 실행 프롬프트 — HumanSearch 여정 기획 마무리 (2026-08-14 밤)

/ strict 모드로 아래를 사람 개입 없이 끝까지 진행하라. 코드 병합(merge)은 하지 마라 — 이번 밤 작업은 **기획 문서 확정과 적대검증까지**다. 소스 코드 구현·PR은 사장님 승인 후 낮에 한다.

## 배경 (이미 확정된 것)
- 마스터 기획: `docs/engineering/humansearch-journey-master-plan-2026-08-14.md` (내가 작성, 사장님 리뷰 4라운드 반영 완료).
- 사장님 확정 결정: ①디스코드 완전 무인(사람 클릭 0회, 상주 브라우저+진단 포트) ②SQLite 1차→Supabase 순차 배치 ③사람인·잡코리아 고점수 부분 자동발송 실험(점수 85·일 상한 10건 제안, 미확정) ④v1~v5 전면 의존 금지 ⑤서치 기준 5종(서울권대 최우선·잦은이직 강한 감점·프리랜서 제외·구조적 글 가점·OTW 우선/Non-OTW는 현직 2년+) ⑥RPS는 프로젝트 생성+필터 세팅 선행 후 필터순회→키워드교체.
- 실측 완료: Aside `--remote-debugging-port=45111` 재시작 성공, 사람인·잡코리아 **사장님 수동 로그인 세션을 자동화가 CDP로 이어받음 확인**(hiring.saramin.co.kr/home, jobkorea searchfirm/home). 자동 자격증명 입력은 실패(저장값 낡음) → "코드가 비번 입력 안 함, 사람 세션 이어받기"로 확정.
- Aside 리서치: "에이전트용 비밀번호 관리자", 자격증명을 에이전트에 노출 않고 사이트에 자동입력. Secure Enclave 로컬 암호화.

## 오늘 밤 할 일 (순서대로, 각 단계 증거 남길 것)

### 1. codex 독립 기획 회수·대조 (V1 트랙)
- 백그라운드 codex 작업(`.claude/private-reviews/codex-humansearch-journey-plan-2026-08-14.md`) 완료 여부 확인. 미완이면 완료까지 대기. 파일 비었으면 codex 출력을 그 경로에 저장.
- codex 기획과 내 마스터 기획을 항목별 대조표로 만든다: 일치/불일치/codex만 잡은 것/내가만 잡은 것. `docs/engineering/humansearch-journey-master-plan-2026-08-14.md` §10 적대검증 로그에 append.

### 2. codex에 2차 과업 — 사장님 결정 반박 + 내 기획 적대검증
- `codex:codex-rescue` 에이전트(name 파라미터 주지 말 것)로 새 codex 실행. 프롬프트에 §8-7 브리핑 지시 블록 첨부. 저장 경로 지정, 첫 줄 `VERDICT:`.
- 시킬 것: (a) 사장님 확정 결정 ①~⑥ 각각을 **적대적으로 반박**하고 더 나은 대안 제시 — 특히 완전 무인의 계정 잠금·약관 리스크, 부분 자동발송의 오발송 리스크. (b) 내 마스터 기획의 가짜 완료·고아 설계·빈틈 공격. (c) 500줄 분할표가 실제로 지켜질 수 있는지, 파일 책임 분리가 맞는지.
- 받은 판정을 §8-6a 검사기로 검사, 위반 시 1회 재요청. 외계어면 원문 보존+내 3층 해석.
- codex 신분 확인: `codex-companion` Bash 실행 있었는지 확인 후 V1로 셀 것.

### 3. Aside 비밀번호 심층 리서치 (미해결 ※ 해소)
- 공식 문서(aside.com/docs, changelog)에서 확인: 자동입력이 (a)사람 승인 필수인지 (b)에이전트가 트리거 가능한 API 있는지 (c)세션/패스키를 자동화가 쓸 수 있는지. WebSearch/WebFetch 사용.
- 결론을 마스터 기획 §9 또는 신설 절에 반영. "Aside 자동입력을 v6가 활용 가능한가 vs 사람 세션 이어받기만 쓸 것인가"를 결정 카드로 정리(사장님 낮 결정용).

### 4. 마스터 기획 최종화
- 위 1~3 반영. `brief-lint.sh` 돌려 위반 0 유지(숫자 첨부, 합격근거 아님 명시).
- 미확정 2개(자동발송 점수·상한)와 사장님 낮 결정 대기 항목을 문서 맨 앞 "사장님 결정 대기" 목록으로 정리.
