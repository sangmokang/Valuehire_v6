# 결론

기존에 모은 후보를 버리지 않고, 학력·완벽한 도구 일치·당장 이직 가능 여부의 비중을 낮춰 실제 업무를 잘할 가능성이 높은 후보를 더 찾는다. 프리랜서와 짧은 재직 반복은 계속 제외하며, 추가 후보는 엄격 추천자와 섞지 않고 별도 목록으로 저장한다.

## 판단 근거

기존 판정은 필수조건 하나가 빠지면 좋은 실무자도 추천 목록에서 사라지는 구조였다. 이번 보조 탐색은 직무 핵심 역량, 유사 업종 경험, 역할 수준, 구체적 성과를 중심으로 다시 보고, 위치·학력·특정 도구 결손은 면접에서 확인할 위험으로 남긴다.

> **무엇을** — 5개 포지션의 저장된 원문 103건에서 직무 적합성이 높은 추가 후보를 다시 선별한다.
> **왜** — 엄격 조건만으로는 네 포지션의 추천 인원이 부족하고, 전환 가능한 강한 실무자를 놓칠 수 있다.
> **버린 길** — 모든 조건을 없애고 점수만 낮추는 방식은 부적격 후보가 다시 섞이므로 사용하지 않는다.
> **대가** — 추가 후보는 학력·위치·특정 도구·도메인 경험 중 일부가 부족해 면접 확인이 더 필요하다.
> **되돌리기** — 엄격 추천 목록은 그대로 보존하고, 이 보조 목록만 제거하면 원래 판정으로 즉시 돌아간다.

## 입력과 범위

- 포지션: `86eyhdzky`, `86eyhdzq1`, `z8nfn6merg`, `86exbvqg6`, `86eyhdzud`.
- 1차 범위: `.claude/private-reviews/codex-5position-search-evidence-2026-08-15/`의 저장 원문 103건.
- 2차 범위: 저장 풀로 포지션별 추가 후보를 만들지 못할 때만 Aside의 기존 로그인 탭을 읽기 전용으로 사용한다.
- 외부 발송, 후보 포털 등록, 자격증명 입력, 탭 닫기, ClickUp 수정은 범위 밖이다.

## 완화 판정 계약

### 계속 유지하는 제외 조건

- 실제 프리랜서 경력이 현재 또는 핵심 최근 경력으로 확인된 후보.
- 회사 단위로 묶었을 때 12개월 미만 재직이 2회 이상인 후보.
- 원문, 화면 캡처, 본문, 파일 지문이 없는 후보.

국내 채용 사이트의 2·3년제 학력은 이번 보조 목록에서는 자동 제외하지 않고 위험으로 표시한다. 사용자가 요청한 “직무 적합성 우선”을 반영한 의도적 완화이며, 엄격 목록에는 적용하지 않는다.

### 직무 적합성 우선 점수

- 일반 포지션 핵심 적합성 = D1 직무핵심역량 + D2 도메인 + D3 역할수준 + D5 구체적 성과. 최대 58점.
- 일반 포지션 보조 후보 = 핵심 적합성 35점 이상, 또는 핵심 적합성 32점 이상이면서 전체 원점수 65점 이상.
- Global Growth 핵심 적합성 = 북미 문화 + creator + viral + category. 최대 90점. 50점 이상을 보조 후보로 본다.
- 학력, 당장 이직 가능 여부, 서울·도쿄 근무 가능성, 더존·J-GAAP·AI character chat 같은 특정 결손은 자동 탈락 대신 `확인 필요`로 분리한다.
- 총점은 사람이 쓰지 않고 저장된 소점수를 코드로 합산한다.

- 후보별 필드: 포지션, 원문 링크, 채널, 원문 파일, 파일 지문, 핵심 적합성 소점수와 근거, 부족 조건, 면접 확인 질문, 저장 상태.

## 합격 조건과 반례

- 저장된 103건 전체가 포지션별 검토 범위에 포함됐다는 집계가 있다.
- 추가 후보의 링크와 본문 지문이 원문 manifest와 일치한다.
- 계산 점수는 JSON 소점수의 기계 합산과 일치한다.
- 기존 엄격 추천자와 추가 후보를 같은 등급으로 표시하지 않는다.
- 반례: 학력만 낮춘 뒤 직무 경험이 약한 후보를 “직무 적합성 우수”로 올리면 실패다.
- 반례: 프리랜서 또는 짧은 재직 반복 후보를 다시 포함하면 실패다.
- 반례: ClickUp에 저장하지 않았는데 저장됐다고 보고하면 실패다.
