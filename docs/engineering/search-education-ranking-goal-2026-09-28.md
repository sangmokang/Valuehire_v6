## 계약과 인수 기준

입력은 후보 본인 프로필의 학교·캠퍼스·학위·전공·졸업 상태·고교 유형 원문과 JD 요건, QS/THE 공개 순위입니다. 출력은 출처·순위판·조회일·확인된 학력·보조 참고 여부이며, 순위를 확인할 수 없거나 학교·캠퍼스·고교 유형이 불명확하면 해당 가중치를 적용하지 않습니다. 동률·구간은 그대로 유지하고, 서로 다른 평가기관 사이에 단일 서열을 만들지 않습니다.

- When 학교 순위를 참고할 때, 시스템은 평가기관의 원문 링크·순위판·조회일을 남겨야 합니다. 검증: 두 URL과 날짜가 정본에 있는지 확인합니다. 반례: 출처 없이 유명 대학 목록만 붙입니다.
- If 후보 본인 원문에 학교·캠퍼스가 없을 때, 시스템은 순위 가중치를 적용하지 않아야 합니다. 검증: 정본과 실행 프롬프트의 누락 처리 문장을 대조합니다. 반례: 직원 학력 표본에서 후보 학력을 추정합니다.
- While 후보를 평가할 때, 시스템은 직무 요건·성과·재직 상태보다 순위를 앞세우지 않아야 합니다. 검증: 두 문서의 우선순위 문장을 대조합니다. 반례: 순위 밖 학교를 자동 탈락시킵니다.
- When 인하대·인천대를 참고할 때, 시스템은 THE 순위를 별도 인천 소재 항목으로 기록해야 합니다. 검증: 정본과 실행 프롬프트의 분리 문장을 대조합니다. 반례: 인천대를 지방 국공립대에 섞거나 인하대를 QS 서울 목록에 넣습니다.
- If 과학고·외고를 우대할 때, 시스템은 후보 본인 원문의 고교와 유형을 확인하고 작은 보조 우대만 적용해야 합니다. 검증: 정본과 실행 프롬프트의 확인·우선순위 문장을 대조합니다. 반례: 직원 학력 분포나 대학명으로 고교를 추정합니다.
