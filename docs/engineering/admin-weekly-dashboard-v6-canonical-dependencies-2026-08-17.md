# Admin Weekly Dashboard v6 canonical dependency overlay — 2026-08-17

## 1층 — 결론

이 문서는 모든 실행 micro가 어떤 검증 완료 기록을 기다리는지 exact ID로 고정합니다. 이름 없는 산문 dependency는 실행하지 않습니다.

## 2층 — 판단 근거

아래 overlay는 조사 문서와 Phase 0 행의 기존 `dependencies` 필드를 전부 덮어씁니다. 한 group의 `consumers` 각각은 `requires_micro_ids` 전부의 독립 PASS가 있어야 합니다. writer 계약을 만들 때 각 ID는 evidence registry의 실제 SHA-256으로 바뀌며, 값이 없거나 `REQUIRED_AT_CONTRACT`로 남으면 BLOCKED_MISSING_DEPENDENCY_HASH입니다.

`requires_blocker_ids`는 micro가 아니므로 PASS hash로 대체하지 않습니다. 해당 정본 결정이나 외부 권한이 해결되기 전에는 그 consumer를 시작하지 않습니다.
