# 최종 V1 기록 지적의 대조

D1은 잘못 입력한 원명령 실패 자체로는 REPRODUCED이다. 다만 그 실패를 통과로 사용하지 않았으며 root는 V1 검토가 끝나기 전에 정확한 원명령으로 이미 재실행했다. final-g2.json/log는 종료값 127 원문 보존, final-g2-recheck.json/log는 scripts/acceptance-hs-gates.sh 종료값 0·262개 수집과 통과이다. 후자는 22:43:45 시작·22:44:08 종료이며 V1이 독립 G2를 실행한 22:50:17보다 앞선다. 두 검증의 후보 다섯 파일 지문은 같다. 추가 반복 실행 없이 이 새 기록을 최종 근거로 사용한다.

정보 1의 이전 카드/증거 숫자는 초기 후보의 역사이다. 검토 중 계약 원문을 바꾸지 않기 위해 final-reviewed-goal-snapshot.md로 고정했고, 최종 V2까지 완료한 후 현재 상태를 카드 앞에 두고 모든 완료 산출물을 수집한다. 239를 최종 후보 수로 주장하지 않는다. 현재 후보는 정조준43·전체262·기존37이며 같은 후보의 session-status는 RED0/31이다.

V1의 신규 고장37개 중31개 단언실패/6개생존은 전체38실행에 정상사본1개가 포함된 수치이다. V1이 정보로 분류한 여섯 생존과 보이지 않는 문자에 대한 해석은 새 V2의 독립 대조 대상이다. root가 미리 합격으로 확정하지 않는다.
