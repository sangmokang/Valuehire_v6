# JD 독립 검증 판정 — 2026-09-22

Claude V1 정적 검증은 실제 CLI 1턴으로 실행되어 FAIL을 반환했다. 도구 사용 없는 정적 검토였으므로 보고서의 “재현” 문구를 실행 증거로 취급하지 않았다. 앞선 도구 허용 호출은 6분 이상 결과 없이 대기하여 중단했고, 외부 도구 없는 호출은 정상 종료했다.

수용·수정: 출처 해시/회사·직무·출처 상태 변경 탐지, 패킷 오류 차단, 별칭 메타데이터로 제목을 바꾸는 우회 차단, 제안의 별도 재조회 플래그, 직접지원 도메인·문구 차단, 잘못된 채널의 구조화된 실패, CLI JSON 왕복 시험. 일반 기술명 ASP.NET/Socket.IO는 지원 주소로 오인하지 않는 반례도 추가했다.

독립 Codex V2는 초기 출처 무결성 반례를 실제 재현하여 FAIL을 반환했다. 수정 후 해시/회사명 변경, 별칭 우회, 제안의 별도 확인 플래그를 재공격하여 집중 검증 PASS를 반환했다.

수용하지 않은 V1 해석: 사용자가 허용한 제안 칸으로의 핵심 단위 배치는 삭제가 아니다. PARTIAL은 영구 필드와 제안 내용의 결과를 나누기 위한 의도된 상태다. 빈 단위/알 수 없는 섹션은 실제 로더가 이미 거부한다. 현재 위험 문자 표에는 치환 누락이 없다. JSON 계수 타입 변경 문제는 실제 측정 코드에 해당하지 않았으며, 실제 CLI 왕복 시험으로 확인했다.

증거 한계: 브라우저 재조회 JSON은 운영자가 수집하는 증거이며 암호학적으로 인증된 브라우저 증명이 아니다. 입력과 해시를 함께 조작할 수 있는 주체에 대한 보안 경계가 아니다. 원문 추출의 사실 누락 여부는 원문-단위 대조로 별도 확인한다.

전체 Strict PASS는 선언하지 않는다. 초기 실패 시험의 선행 로컬 커밋을 누락했다. skill-creator 공식 검사기는 기존 Python 환경의 PyYAML 부재로 실행하지 못했고, 대신 정본/양쪽 연결/필수 의존성/문서 기본 구조와 실제 공통 CLI 시험을 수행했다. 새 의존성을 설치하지 않았다.
