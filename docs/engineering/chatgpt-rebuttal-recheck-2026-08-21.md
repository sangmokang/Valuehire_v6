## 3층 증거 원문

### E1. 서버 검사 실행 줄 전수 변조 — 23개 중 8개만 탐지

방법: 저장소를 격리 복제한 뒤 `.github/workflows/verify.yml`의 스크립트 실행 줄 23개를 **한 줄씩** `run: echo bash …`(실행하는 척만 하고 안 함)로 바꾸고, 워크플로 내용을 읽는 검사기 전부와 로컬 훅 판정식을 돌렸습니다.

```text
TOTAL_CI_EXEC_LINES=23
DETECTED   8  : principles-check, hs-gates, hs-gates-mutations, hs-gates-antiforge,
                acceptance-0-7, acceptance-0-5, scan-data-exposure, verify-ac-m
UNDETECTED 15 : principles-mutations, guard-global-skill-files, cleanroom 8종,
                0-2-unreachable-content, 0-6, hs-a3, hs-a4, secret-webhook-vendor
```

→ 무엇을 시켰나: 검사 한 줄씩 껐습니다. 무엇이 나왔나: 23개 중 15개는 꺼도 아무도 실패하지 않습니다. 나쁜 소식입니다.
→ 게다가 탐지된 8개 중 2개(`acceptance-0-5`·`acceptance-0-7`)는 **로컬 훅만** 잡습니다. 원칙 P15③(“로컬에만 있는 검사는 없는 것으로 친다”)을 적용하면 서버 기준 탐지는 **6개**입니다.

변조 형태를 바꾸면 숫자가 달라집니다(표적 재현).

| 변조 형태 | 결과 | 확인 |
|---|---|---|
| `run: echo bash X` | 8 탐지 / 15 무탐지 | 전수 실증 |
| 실행 줄 삭제 | +1 탐지(`0-6`을 `acceptance-0-5`가 잡음) | 표적 실증 |
| `if: false` (리터럴) | 탐지(로컬 훅) | 표적 실증 |
| `if: ${{ false }}` (표현식) | **무탐지** — 로컬 훅·`verify-ac-m` 모두 통과 | 표적 실증 |
| `cat X \| bash` | 무력화가 아님(실제로 실행됨, 종료값 0 동일) | 표적 실증 |

→ 해석: “8/15”는 **`echo` 치환이라는 한 가지 공격에 대한 탐지율**이지 전체 안전도가 아닙니다. 이 구분은 codex(V1)가 제 초안을 FAIL 판정하며 지적한 것이고, 실행해 보니 지적이 옳았습니다.

### E2. 전역 지침 파일 잠금 장치의 동시 실행 경합 — 결정적 재현 성공

가짜 홈 디렉터리 샌드박스에서 재현했습니다(실제 지침 파일 무접촉).

```text
NATURAL_RACE_HIT=0   (주입 없는 자연 동시 실행 200회)
--- 상태 확정 직후 sleep 2 주입(로직 불변, 순서만 고정) ---
RECOVERED_WITHOUT_INTEGRITY_PROOF: 원래 권한 복구; 검증 PASS로 세지 말 것
B_recover_rc=0
PASS: 2개 파일 lock 완료 (444, 우발적 변경 억제)
A_lock_rc=0
사후 권한: 444 / 444
상태 파일: 없음
```

→ 무엇을 시켰나: 잠금(lock)과 복구(recover)를 동시에 돌렸습니다. 무엇이 나왔나: 잠금이 **“성공”을 출력하고 종료값 0**을 냈는데, 파일은 읽기 전용으로 남고 되돌릴 기록은 사라졌습니다. 나쁜 소식입니다.
→ 다만 자연 발생 200회에서 0건이므로 **발생 확률은 낮습니다.** “동시에 돌리면 깨진다”가 아니라 “동시에 돌리면 깨질 수 있고, 깨지면 자동 복구 경로가 사라진다”가 정확한 표현입니다. 심각도는 중간이 적절합니다.
→ `scripts/guard-global-skill-files.sh`에 상호 배제 장치(`flock` 등)가 없음을 확인했습니다(검색 결과 0건).

→ 뜻: 반박이 권한 “신뢰의 뿌리를 깃허브에 두자”는 지금 불가능하고, “어느 커밋이 초록이었는지 확인”은 지금 가능합니다. 유료 전환 또는 저장소 공개가 유일한 우회로이며, 무료 조직으로 이전해도 비공개 저장소 제한은 그대로입니다.

### E6. 반박이 다루지 않은 더 급한 결함 — 과거 기록 비밀 스캔이 통과함

## 이번 재검토의 한계

- 변조 5종 × 23줄 전수 스윕은 **`echo` 치환만 완주**했습니다. 나머지 4종은 대표 줄 표적 실증입니다(회당 100초를 넘겨 전수는 중단).
- 동시 실행 경합은 순서 고정을 위해 `sleep 2`를 주입한 사본으로 재현했습니다. 로직은 바꾸지 않았지만, 자연 상태 발생률은 200회 0건 외에 측정하지 않았습니다.
- 403 응답이 요금제 때문이라는 것은 응답 본문과 공식 문서로 판단했습니다. 다른 토큰으로 교차 확인하지 않았습니다.
- 판정문 앞부분과 뒷부분의 충돌은 확인만 했고 **문서를 수정하지 않았습니다**(사장님 결정 대기).
