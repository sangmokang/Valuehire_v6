# LinkedIn RPS InMail 본문 정본

최종 확인: 2026-09-22. 적용 대상: LinkedIn Recruiter(RPS) 후보자 문안의 작성과 검증.

## 결론과 완료 기준

RPS는 제목 + 빈 줄 + 본문 합산 1,900자를 **내부 작성 한도**로 사용한다. 이 값은 최신 플랫폼 시스템 한도라는 주장이 아니다. 회사 소개를 포함하고, 책임 범위·필수/우대·경력 연수·핵심 역량·주요 수치와 실질 조건을 명확한 소제목과 짧은 항목으로 보존한다. 장황한 어미와 반복 설명을 줄이는 것이지 후보자의 판단 정보를 삭제하는 것이 아니다.

발송과 템플릿 저장은 별도 외부 행동이다. 현재 요청이 문안 작성뿐이면 로컬 초안과 검증에서 멈춘다.

## 1. 작성 계약

| # | 계약 | 검증 |
|---|---|---|
| L1 | 제목 + `\n\n` + 본문 합계 1,900자 이하 | `measure.compose()` + `over_limit()` |
| L2 | 회사의 사업·제품·유효한 규모/재무/성장 사실과 역할 연결을 압축해 포함 | 회사 소개 독립 검사 |
| L3 | 책임 범위, 필수·우대 구분, 경력 연수, 핵심 역량, 주요 수치·조건 보존 | 원문 단위 대조 |
| L4 | `[회사 소개]`, `[팀·역할]`, `[주요 업무]`, `[자격요건]`, `[우대사항]`처럼 빠르게 읽히는 구조 사용 | 소제목 존재 검사 |
| L5 | 원문에 없는 보상·직급·조건을 만들거나 조건을 강화·약화하지 않음 | 원문·출처 대조 |
| L6 | 후보자 이름 하드코딩, 원시 변수, 이모지, 과장·상투 문구, 굵게/해시 마크다운 금지 | `scan_inmail()` |

## 2. 압축 순서

한도를 넘으면 다음 순서로 줄인다.

1. 반복 CTA와 장황한 인사말
2. 같은 의미의 반복 설명과 긴 종결어미
3. 한 문장에 중복된 수식어와 불필요한 영어 치환
4. 후보자 판단에 덜 중요한 회사 부가 이력

회사 소개 전체, 책임 범위, 필수·우대 구분, 경력 연수, 핵심 수치·조건을 삭제해 맞추지 않는다. `글로벌 사업의 P&L을 책임지며, 매출 구조와 비용 구조를 함께 설계해요`는 `글로벌 사업 P&L 책임, 매출·비용 구조 설계`처럼 줄일 수 있다. 의미를 해독하기 어려운 키워드 나열은 허용하지 않는다.

## 3. 회사 소개와 역할 연결

현재 근거에서 사업·제품, 고객·거래·매출 규모, 투자·재무 상태, 성장 방향 중 이 포지션에 유효한 사실을 선택한다. 실적과 목표, MAU와 DAU, 이번 투자와 누적 투자를 구분하고 시점을 붙인다. 회사명·업종 한 줄은 불합격이다.

상세 출처 URL과 불확실성은 로컬 증빙에 남긴다. 후보자 문안에는 검증된 사실만 쓰고 내부 출처 ID나 `미확인` 표식을 노출하지 않는다. 회사 사실을 제시한 뒤 팀의 미션이나 해당 포지션의 책임으로 연결한다.

## 4. 구조와 문체

짧은 인사말 뒤에 회사 소개, 팀·역할, 업무, 자격요건, 우대사항, 성장·실질 조건, 핵심 전형 순서로 쓴다. 명확한 제목과 하이픈 항목은 허용하며, 반복되는 `~합니다` 문장이나 마침표 없는 키워드 덩어리를 피한다.

다음은 금지한다.

- 특정 후보자 이름 하드코딩 또는 `{{first_name}}` 같은 원시 변수
- `귀하의 경력을 주목하여`, `좋은 기회가 될 것입니다` 같은 상투어
- `폭발적 성장`, `업계 최고`, `완벽한 기회` 같은 근거 없는 과장
- 이모지, `**굵게**`, `# 제목`
- 회사 직접지원 링크·이메일·지원 버튼 안내
- 일반 회사 주소, 정규직 안내, 채용 시 마감, 자유양식 이력서, 전형 추가·생략 가능, 허위기재·개인정보·서류 파기 안내

계약직, 해외 근무·이주, 필수 출장·교대근무, 필수 자격·포트폴리오, 수습, 핵심 전형, 동의 기반 레퍼런스 체크처럼 판단을 바꾸는 조건은 보존한다.

## 5. 검증과 외부 행동

1. `measure.compose(subject, body)`로 합산 범위와 실제 codepoint/UTF-16 수를 기록한다.
2. 회사 소개 존재·충실도와 공식 JD 원문 보존을 서로 다른 검사로 판정한다.
3. 삭제 문구와 의미상 변형, 직접지원 경로, 원시 변수, 이모지, 과장을 검사한다.
4. 골든샘플은 구조·설득 방식에만 사용하고 다른 회사의 수치·전형·역할 사실을 가져오지 않는다.
5. 현재 요청이 문안 작성뿐이면 저장·발송하지 않는다. 저장이 명시적으로 승인된 별도 작업에서는 저장 후 다시 불러온 문자열까지 일치해야 완료다.

## 6. 과거 실행 기록

2026-09-22 뤼튼테크놀로지스 Finance Data Analyst (FP&A) 템플릿을 본문 1,381자·불릿 0개·8문단으로 저장한 사실은 과거 관찰로 보존한다. 그러나 `불릿이 없거나 아주 적어야 한다`와 `한 편의 글이어야 한다`는 판단은 현재 정정에서 `SUPERSEDED`다. 활성 규칙은 명확한 소제목과 간결한 항목을 허용하고 요구한다.
