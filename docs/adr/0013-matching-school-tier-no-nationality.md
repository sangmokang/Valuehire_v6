# 0013 매칭에 학교 등급은 반영하고 국적 감점은 하지 않는다
- 상태: 승인(학교) / 거절(국적 감점)
- 날짜: 2026-09-23
- 발단 명령: 원문 미보존 — 요지: 상위권 대학을 우대하고 비한국 국적은 감점하라
- 연결: Jev 근거평가 WU1 프롬프트 v3

## 배경
후보 매칭 점수에 학교와 국적을 반영할지 정해야 했다.

## 결정
- 학교: 버전이 붙은 등급표(`contracts/school-tier.json`, 작성 예정)로 코드가 판정하고 가중치를 준다. 학교만으로 자동 탈락시키지는 않는다.
- 국적: 감점하지 않는다. 대신 업무 가능 조건(한국어 업무 능력, 국내 취업 자격)에 가중치를 준다. 국적 값은 점수에 영향이 없다는 것을 음성 시험으로 보장한다.

## 버린 대안
- 국적 감점: 고용차별 소지가 있다(국가인권위원회법·고용정책기본법). Claude가 거절하고 업무 가능 조건으로 대체안을 냈다.

## 대가 / 재검토 조건
국적 감점을 다시 요청받으면 업무 가능 조건 대체안을 다시 제시한다. 학교 등급은 재논의 없이 반영한다.
