# 결정 기록(ADR)

ADR(Architecture Decision Record, 결정 기록)은 **사장님이 방향을 정한 결정**과
**되돌리기 어려운 결정**을 한 건에 한 파일로 남긴다. 무엇을 했는지는 커밋과
`docs/engineering/`에 남는다. 여기에는 **왜 그렇게 정했는지와 어떤 명령에서
출발했는지**를 남긴다.

## 규칙

1. **한 결정 = 한 파일**, 파일명은 `NNNN-짧은-이름.md`이고 번호는 쓴 순서대로 붙인다.
2. **본문은 고치지 않는다.** 결정이 바뀌면 새 ADR을 쓰고, 옛 ADR은 `상태:` 줄만
   `대체됨 → NNNN`으로 바꾼다. 그래야 생각이 흘러온 순서가 남는다.
3. **발단 명령**에는 사장님 원문을 인용한다. 원문이 남아 있지 않으면
   `원문 미보존 — 요지:`라고 밝히고 요지만 적는다. 원문을 지어내지 않는다.
4. 후보자 실명·연락처·비밀값은 적지 않는다.
5. 쓸 대상: 사장님 결정, 되돌리기 어려운 설계, 다음 세션이 다시 물을 법한 것.
   일상적인 구현 선택은 커밋 trailer(`Rejected:`, `Directive:`)로 충분하다.

## 틀

```
# NNNN 제목
- 상태: 승인 | 거절 | 대체됨 → NNNN
- 날짜: YYYY-MM-DD
- 발단 명령: "사장님 원문"
- 연결: 관련 ADR·문서 경로

## 배경
## 결정
## 버린 대안
## 대가 / 재검토 조건
```
