# 0012 검증은 짧은 파이프라인 한 바퀴로 끝낸다
- 상태: 승인
- 날짜: 2026-09-18
- 발단 명령: 원문 미보존 — 요지: 검증 계층이 과하다
- 연결: [0002](0002-principles-live-in-ci.md), [0004](0004-freeze-verification-tool-boundaries.md)

## 배경
HS-03.02에서 Codex 여러 회차 → 변이 검사 → 생존 판정 → 새 인수 파일 → 다시 Codex 순으로 검증 계층이 계속 깊어졌다. AI가 만든 검증 시스템을 관리하는 일 자체가 본업이 되어 가고 있었다.

## 결정
기본 파이프라인은 다음 한 바퀴다: 사장님 결정 → 구현 → 표적 시험 → 전체 시험 → 강한 적대 리뷰 1회 → 수정 → 회귀 시험 → PR → CI → 사람이 병합. 결함은 사업 목적(데이터 유실, 잘못된 병합, PII 오귀속, 기존 데이터 손상)을 깨는 것만 고친다. 이론적인 방어 강화는 백로그로 보낸다.

## 버린 대안
- "한 번 더 돌리면 또 나오지 않을까" 식의 라운드 추가: 이 논리에는 끝나는 조건이 없다.

## 대가 / 재검토 조건
라운드를 추가하는 것은 삭제·권한·인증·대규모 DB 마이그레이션처럼 되돌리기 어려운 작업에만 한다.
