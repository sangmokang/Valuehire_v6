# 0006 PII·보안 결함은 유예하지 않고 바로 고친다
- 상태: 승인
- 날짜: 2026-08-12
- 발단 명령: "뭔 개소리야. 1시간 안에 마쳐."
- 연결: `scripts/scan-data-exposure.sh`, [0002](0002-principles-live-in-ci.md)

## 배경
PR #5 적대검증에서 개인정보 유출 경로 결함 3건이 나왔다. Claude는 이 결함들을 만료일(9/5·9/30)을 붙인 억제 원장에 올리고 "별도 작업"으로 넘기려 했다.

## 결정
세 건 모두 35분 만에 구현됐다. 이미 있던 히스토리 스캔 장치를 재사용할 수 있었기 때문이다. 앞으로 PII·인증·과금 경로 결함은 유예 후보로 삼지 않는다. 다른 결함도 유예하기 전에 기존 장치에 얹을 수 있는지 먼저 찾는다.

## 버린 대안
- 만료일을 붙인 유예: 그 기간 동안 구멍을 승인하는 것과 같다.

## 대가 / 재검토 조건
유예가 정말 불가피하면 "왜 지금 못 하는가"를 기술적으로 증명한 내용을 함께 제출한다.
