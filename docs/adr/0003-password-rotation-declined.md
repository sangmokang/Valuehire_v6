# 0003 유출된 계정 비밀번호는 회전하지 않는다
- 상태: 거절(회전 제안을 사장님이 거절)
- 날짜: 2026-08-04
- 발단 명령: 원문 미보존 — 요지: 외부 리뷰가 권고한 비밀번호 변경을 거부
- 연결: `.claude/private-reviews/gptreview-20260804-repo-wide.md` P0-1(로컬 전용)

## 배경
평문 비밀번호가 로컬 커밋에 들어갔다. 2026-08-06 실측 결과, 해당 커밋은 원격에 push되지 않았고 저장소는 private였다.

## 결정
비밀번호를 회전하지 않는다. 대신 기술적 조치(히스토리 청소, 비밀 스캔, pre-push 훅)로 대응한다.

## 버린 대안
- 비밀번호 회전: 사장님이 리스크를 알고 거부했다. 2026-08-06 세션에서 이 결정을 회수하지 않고 다시 권고한 사고가 있었다. 이 ADR은 그런 재요구를 막기 위해 남긴다.

## 대가 / 재검토 조건
같은 비밀이 다른 저장소(Valueconnect-Ops) 원격 브랜치에 남아 있다. 노출 범위가 외부로 넓어지면 사실을 보고한다. 회전을 다시 요구하지는 않는다.
