# 0005 보고는 3층 구조로 쓰고 외계어를 금지한다
- 상태: 승인
- 날짜: 2026-08-12
- 발단 명령: 원문 일부 — "글로브가 뭐지?", 해석 없는 터미널 출력에 "무슨 내용인지도 모름"
- 연결: strict §8 브리핑 계약

## 배경
판정서와 보고가 "한국어인데 외계어"였다. 반대로 쉽게 쓰라고 하면 내용이 깎였다.

## 결정
보고는 3층으로 쓴다(1층 결론은 전문용어 없이 → 2층 근거·버린 길 → 3층 증거). 전문용어는 처음 나온 문장 안에서 풀이한다. 출력 블록에는 해석을 붙인다. 번역은 표현에만 적용하고, 판정 강도와 결함 개수는 줄이지 않는다.

## 버린 대안
- 보고 품질을 기계로 채점하기: 4번 만들어서 4번 다 뚫렸다(무의미한 문장은 통과하고, 잘 쓴 문장은 오탐했다). 지금 검사기는 "아예 빠진 것"만 세며 경고만 낸다.

## 대가 / 재검토 조건
품질 판정은 사람이 한다. 검사기 숫자는 참고용이다.
