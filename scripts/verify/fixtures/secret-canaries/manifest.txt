# 비밀 규칙 커버리지 manifest — capability → 양성 카나리 → 그 카나리가 잡아야 하는 규칙 id
#
# 왜 필요한가 (2026-09-11 Codex 적대검증 C2): 카나리가 어떤 규칙을 대표하는지 아무도
# 적어 두지 않아, 규칙 25개 중 21개는 통째로 사라져도 검출 집합이 안 변했다.
#
# 형식(탭 4칸): <capability>\t<카나리 설명>\t<규칙 id 쉼표목록>\t<묶은 근거>
#   · 카나리 설명은 positive.txt 의 첫 칸과 **글자 그대로** 같아야 한다(그것이 키다).
#   · 규칙 id 는 .secret-patterns.default 의 규칙 줄 바로 앞 `# @id:` 주석에서 온다.
#   · 판정은 scripts/verify/check-secret-canary-coverage.sh 가 한다. 적어 두기만 해서는
#     통과하지 못한다 — 적힌 규칙이 그 카나리로 **실제 매칭되는지** 실행으로 확인한다.
#
# 규칙 25개 = 카나리 25개일 필요는 없다. 다만 아래 벤더 키처럼 접두사가 규칙마다 다른
# 묶음은 한 값으로 여러 규칙을 만족시킬 수 없어 결과적으로 1:1 이 된다. 묶음의 의미는
# "같은 위협을 막는 규칙들"이고, 그 근거를 네 번째 칸에 적는다.
