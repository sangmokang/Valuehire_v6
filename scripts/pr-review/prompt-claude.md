3. 찾을 것: 정확성 버그, 개인정보·비밀값 노출, 보안 결함, 대상을 실제로 보지 않는 테스트, 사업 목적과 어긋난 변경. 스타일·취향·리팩터링 제안은 적지 마라. 오버엔지니어링을 권하지 마라.
4. 각 발견에는 Codex 가 재현할 수 있게 근거(파일:줄, 입력 → 잘못된 결과)를 붙인다.
